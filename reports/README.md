# reports/

Agent-generated work products — **not documentation**.

These are artifacts produced by the autonomous governance agents while doing
their jobs: external governance audits, ecosystem health leaderboards,
distribution/outreach drafts, research notes, and session summaries. They are
kept for provenance and reuse, but they describe point-in-time findings, not
how to use the CLI or the protocol. For documentation, see [`docs/`](../docs/).

- `audits/` — external DAO/governance audits and the audit corpus index schema, plus governance-health leaderboards (v2–v4)
- `distribution/` — outreach drafts, social posts, posting runbook, post history
- `research/` — treasury/protocol/bundler research notes
- `sessions/` — session summaries, handoffs, state-of-the-org reports
- `gaas/` — governance-as-a-service offering and revenue strategy docs
- `OPERATOR-STATE.md` — operator-facing rolling state file (rewritten periodically by agents)
